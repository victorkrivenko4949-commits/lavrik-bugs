# 🐞 lavrik-bugs — баги от Лаврика

Сюда Лаврик кидает ошибки (текстом, голосом, со скринами), а агент забирает их отсюда и чинит.

## Для Лаврика — как сообщить об ошибке

**Самый простой путь (с телефона или компьютера):**

1. Открой страницу https://victorkrivenko4949-commits.github.io/lavrik-bugs/
2. Нажми **🎤 Рассказать голосом** и расскажи, что сломалось (или напечатай).
3. Нажми **Отправить** — откроется GitHub с уже заполненной формой.
4. Перетащи скриншот в поле «Что случилось?» (или вставь: Ctrl+V / «Вставить»).
5. Нажми зелёную кнопку **Submit new issue**. Всё!

**Без страницы:** https://github.com/victorkrivenko4949-commits/lavrik-bugs/issues/new/choose → «🐞 Сообщить об ошибке». Голос — микрофон на клавиатуре телефона.

Нужен аккаунт GitHub (бесплатный). Через минуту после отправки в баге появится ответ «Принято» — значит, дошло.

## Для владельца

- **Включить страницу с голосом:** Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save. Через 1–2 минуты заработает ссылка выше.
- Все баги: https://github.com/victorkrivenko4949-commits/lavrik-bugs/issues?q=is%3Aissue+is%3Aopen+label%3Abug
- Чтобы агент починил: скажите «посмотри баги Лаврика» — агент прочитает открытые issue, скачает скрины по ссылкам из текста, исправит в нужном репозитории (например FORMYLA) и отпишется в issue.

## Как это устроено

| Файл | Что делает |
|---|---|
| `index.html` | Страница для телефона: голосовой ввод (Web Speech API, ru-RU) → предзаполненная форма на GitHub |
| `.github/ISSUE_TEMPLATE/bug.yml` | Форма бага на русском: где, что, как повторить, ссылка, важность |
| `.github/workflows/auto-reply.yml` | Автоответ «Принято» + метка `bug` на каждый новый баг |
